# 09 · 程序化动画与敌人 AI：骨骼、步态、令牌与听觉

> 上游案例里没有一帧预制的走路动画：机器狗的四条腿是当场算的。本层把一个「会动、会追、会听」的敌人系统拆成可复用的最小实现。适用于任何单文件 3D 场景里的程序化角色与轻量 AI；不依赖动画文件、不依赖导航网格资产。

## 骨骼与部件

- 四足骨架四个关键参数：大腿长 `L1=0.4`、小腿长 `L2=0.42`、站立高度 `stand=0.72`、脚半径 `footR=0.046`；髋部左右 `hipX=0.165`，脚位前后 `footZ=[0.37,0.37,-0.42,-0.42]`（`[src:pretty:L55739-L55749]`）。
- 骨骼命名固定：`root → body → neck/head/turret/gun/antenna`，四条腿为 `abd/thigh/shin + FL/FR/RL/RR`——名字即文档，自检展台与错误分诊都靠它（`[src:pretty:L55756-L55756]`）。
- 部件用参数几何拼：圆管、圆环、挤出板；同一套材质目录（shell/metal/glow）供整机复用。

## 步态：脚掌落点，不是走路动画

核心思想：**身体只负责前进，脚负责「该落哪」**。每一帧：

1. 按速度预测下一落点，检查四只脚当前的世界位置与预测点的水平距离；
2. 按对角步序成对迈步：`wm = [[0,3],[1,2]]`——前左+后右、前右+后左（`[src:pretty:L56674-L56677]`）；
3. 触发阈值：移动中 **0.09m（9 厘米）**，站立超过 0.25s 后收紧到 0.035m（`[src:pretty:L57233-L57233]`）；
4. 迈步时记录 `from/to`，用 smoothstep 插值脚掌位置，叠加 `sin(π·t)·lift` 的抬脚高度；`lift = 0.065 + min(0.09, speed·0.02)`（`[src:pretty:L57235-L57235]`、`[src:pretty:L57249-L57249]`）；
5. 落地那一帧发 `enemy:step` 音效——脚步声与步态天然同步。

关节角不需要动画曲线：用 `L1/L2` 反解两段腿的 IK，脚掌目标一变，膝关节就跟着变。坡地/台阶只改 `to.y = groundHeight(x,z)`，不需要额外状态。

## 敌人状态机

单一入口切换四个状态，计时器与感知量全部挂在实体上：

| 状态 | 进入条件 | 行为 |
| --- | --- | --- |
| `patrol` | 默认 | 沿巡逻点慢走；`home` 记录驻点 |
| `investigate` | 听到枪声 / 队友 rally / 被挑衅 | 走向 `lastKnown`，超时回 patrol |
| `engage` | 看见玩家持续 `seeT > C`（巡逻时阈值更严） | 保持距离、开火、申请攻击令牌 |
| `search` | 丢失视线 `noSeeT > loseSight` | 搜索 `searchTime + rng*3` 秒后放弃 |

感知参数集中在 TUNE 表：`sightRange 45`、`sightCone 200°`、`loseSight 4`、`searchTime 8`、`hearRadius 45`（`[src:pretty:L57426-L57434]`）。

## 攻击令牌

**不是所有敌人都能同时开火**：全局令牌池 `maxTokens: 2`（拥挤时 `maxTokensCrowd: 3`），拿到令牌才能进入射击位；开火后 `tokenGap 1.25s` 才释放。效果是「轮流上」的压迫感，同时把伤害峰值与音效并发压在预算内（`[src:pretty:L57433-L57434]`）。任何带远程敌人的场景都应先实现令牌，再调伤害。

## 听觉与感知

- 枪声不是「声音文件」而是事件：玩家开火 → `events.emit("weapon:fire")` → 半径 `hearRadius` 内的敌人收到 `alert(pos)`，进入 investigate（`[src:pretty:L57433-L57433]`）。
- 视线判定三段式：距离 → 视锥点积（`cos(sightCone/2)`）→ `physics.lineOfSight` 射线；避免每帧对全场做昂贵 raycast。
- 感知有惯量：`exposure` 随可见时间上升、丢失后下降——避免敌人「瞬移式」警觉。

## 寻路与预算

- 敌人保留 `path`/`wp` 航点与 replan: 0.6s 的重规划节拍（`[src:pretty:L56654-L56654]`、`[src:pretty:L56742-L56742]`）；网格寻路只在地形变化或目标移动时重算。
- 对象池：`poolGulls 10 / poolHounds 8 / maxWrecks 5 / maxBolts 32`——出生即复用，不在战斗热帧 new。
- 随机种子独立（`eseed 9001`），同 seed 的战斗回放可复现。
