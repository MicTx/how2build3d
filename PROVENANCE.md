# 来源说明 · Provenance

## 研究对象 · Research source

本项目研究 Saltline 的单文件 Three.js 实现。出处见 [Three Games 合集](https://claude.ai/artifact/MXxb36zKgN261ckbGhmNin)、[Saltline 原作](https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp)及 [Megasu 收录的中文版本](https://github.com/Megasu/jimao-3a-game)。研究夹具取自后者的 `index.html`；保留的是研究时版本，不等同于上游当前分支。

The frozen HTML has SHA-256 `9e55b5200b088adaf8e1152da04efc0d3b25e236e6baf2dee96f81e23e084966`. Line citations in the research notes refer to that file (`src:L…`) or its formatted JavaScript (`src:pretty:L…`). The public snapshot distributes the guides, examples and attributed ports, **not the original research fixture**. You can build the public examples without it.
