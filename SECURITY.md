# 安全报告 · Security policy

## 私密报告 · Report privately

如发现安装器写入了预期之外的位置、导出包含敏感文件，或示例加载了未声明的外部资源，请通过 [GitHub 私密漏洞报告](https://github.com/MicTx/how2build3d/security/advisories/new) 联系维护者。不要在公开 issue、PR、截图或日志中披露细节。

Name the affected commit, the command or example involved, the expected boundary and what crossed it. Use synthetic inputs: do **not** send live keys, private files or customer data. If you cannot access the private form, open an issue asking only for a private contact channel; do not include the report itself.
