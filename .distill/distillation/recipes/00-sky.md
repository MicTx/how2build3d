# 配方 00 · 程序化黄昏天空

> 复刻 `SALTLINE_SKY` 的决策顺序 [src:L4207-L4295]，配套代码图集 B。

## 配方

1. **输入**：太阳方向 `dir`、三色 `zenith/horizon/horizonAway`、雾色（一张常量表 [src:pretty:L1044-L1068]）、时间 uTime、闪电 uFlash、共享噪声纹理 [src:L4206-L4206]。
2. **云甲板形状**：用 fbm5 生成向东滚的云带；云底 ridged 细节随距离衰减抗锯齿 [src:L4230-L4243]。
3. **构图铁律**：云甲板在朝日方向留缺口，太阳盘"永远烧穿、绝不躲在实云后" [src:L4243-L4251]。
4. **体积感近似**：密度梯度朝太阳 = 云底自阴影；薄处透冷光、缺口边缘暖光斜照 [src:L4254-L4269]。
5. **事件**：云内片状闪电走 `uFlash`，CPU 端 `power*exp(-5t)*(0.55+0.45*sin(47t)*sin(13t+1))*.35` 衰减，t>0.9 归零 [src:L4269-L4272] [src:pretty:L7000-L7024]。
6. **收尾**：远云融进地平线色 [src:L4272-L4291]；太阳盘不进 PMREM（由平行光充当）[src:L4279-L4279]；地平线下用海雾兜底 [src:L4284-L4284]。

## 取舍与失败模式

- **取舍**：云的"物理"全是近似（梯度当自阴影），换来一个 pass 出完整天空。
- **失败**：太阳被云挡住 → 检查缺口 mask 是否随太阳方向旋转；远场走样 → 检查距离衰减项 [src:L4237-L4237]。
- **验收**：同 seed 截图 diff = 0；云隙内太阳盘可见；闪电不过曝到全屏。

## 实施顺序

1. 先建常量表（太阳/三色/雾）与共享噪声纹理 [src:pretty:L1044-L1068] [src:L4206-L4206]；
2. 写全屏 sky mesh 的 frag，先只有渐变，验收"黄昏色"再叠云 [src:L4207-L4212]；
3. 加 fbm 云甲板与距离衰减，验收"远场不走样" [src:L4230-L4243]；
4. 挖云隙、锁死太阳位置，验收构图铁律 [src:L4243-L4251]；
5. 最后接 `uFlash` 与 CPU 衰减曲线，验收闪电不过曝 [src:L4269-L4272] [src:pretty:L7000-L7024]。

## 与其他配方的接口

天空输出的是**光照氛围**，海面配方（01）用同一太阳色做高光 [src:pretty:L1044-L1068]；后处理配方引用本配方的 `uFlash` 与雾色做远场融色 [src:L4612-L4613]。volSteps 由画质档统一供给，不在天空内部硬编码 [src:pretty:L1044-L1068]。
