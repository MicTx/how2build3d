# 05 · 程序化资产：纹理、几何与标识的生成式配方

> 「素材保存成生成它的代码」是本作的核心哲学。本篇拆三类生成器：噪声纹理、
> Canvas 标识、几何拼装——全部零外部文件。

## 噪声与纹理

**噪声纹理是全场景的地基**，一条链路两处实现：

1. **CPU 端**（JS）：xorshift32 伪随机 `t^=t<<13; t^=t>>>17; t^=t<<5` 填充 256×256×4 = 262,144 字节的 Uint8Array，上传为 RGBA 纹理 [src:L4206-L4206]。这张噪声纹理的种子**硬编码为 `2654435769`**，同一构建每次生成同一张纹理——**噪声也是确定性的**。注意别把它和 `__G.rng` 混为一谈：后者是全局 PRNG，由 URL `?seed` 参数初始化（默认 4207），供场景摆放等玩法用途，不参与这张纹理 [src:pretty:L59314-L59318]。
2. **GPU 端**（GLSL）：value-noise `n2(p)` 从该纹理查值，`fbm5/fbm3` 用固定旋转矩阵 `mat2(1.6,1.2,-1.2,1.6)` 和偏移 17.3 迭代升频 [src:L4192-L4195]。5 octave 用于天空云层，3 octave 用于廉价表面（锈迹、污渍）——同一张 256² 纹理被所有着色器复用。

**表面材质的雨湿/宏观变化**不进纹理，进 uniform：`uSlWetP`（湿润参数）、`uSlMacro`（宏观色彩变化）、`uSlUv`（平铺比例）、`uSlX`（室内系数）由材质工厂按需注入 [src:L5318-L5318]。"潮湿的地面"不是贴图换帧，是 shader 参数。

## 几何拼装

没有模型文件，一切几何来自 three 内置几何的**变换与合并**（L4191 巨行）：

- **拼装原语**：Box/Cylinder/Lathe 等参数几何（上游区域 `new Qe(` 装配调用 十八 处 [src:pretty:L1-L25]）经 applyMatrix4 摆位后 mergeGeometries 合并成单网格 [src:pretty:L1044-L1068]——集装箱、仓库、码头、枪械、机械敌人都是"积木 + 合并"的产物。合并前先 toNonIndexed()（6 处调用 [src:pretty:L1-L25]），因为要给每个面独立写入 attribute（如闪烁相位）。
- **实例化**：InstancedMesh 用于重复单元（集装箱阵列、雨滴粒子 `attribute vec4 aPar` [src:L5461-L5461]、海鸥群 [src:L5474-L5474]），单 draw call 铺满全场。
- **法线后处理**：拼装后 computeVertexNormals（7 处 [src:pretty:L1-L25]）重算光照面。
- **关卡参数化**：整个港区是一个常量表——可行走盒 `(-四十,0,-三十)~(四十,三十,三十)`、地面 y=0、海面 y=-1.6、码头 x=三十、太阳方向/颜色/强度 [src:pretty:L1044-L1068]。世界坐标即数据结构。

## Canvas 贴图

**标识与文字**走 Canvas 2D（L5294 巨行，展开后约 33060-33200 行）——这是"港口标识牌"质感的来源：

- **啃咬边缘**：`Ks()` 用 `destination-out` 合成模式把完整形状"啃"出破洞（`ra()` 生成随机多边形孔洞，幂律 `pow(s(),3)` 控制孔径分布）+ 划痕（随机线段，`lineWidth 0.5~3` 按 s² 偏细）+ 点状锈斑 + 径向渐变污渍 [src:pretty:L33030-L33054]。四个 pass 叠出"用了二十年的铁牌"。
- **文字排版**：`qa()` 完整实现了一个小型排版引擎——字距（`spacing = s*0.06`）、字重、等宽/无衬线选择、**连笔桥**（`bridges`，印刷术语）、超宽缩放（`maxW/fitW`）、逐字 measureText 后 fillText [src:pretty:L33030-L33054]。枪身标签、集装箱编号、仓库警示语全部经它排版。
- **色彩科学不缺席**：Canvas 出来的纹理同样过色彩管理（three 端 colorSpace 处理在 [src:pretty:L1-L25] 的导出表里）。

## 配方总结

| 资产类别 | 生成器 | 输入 | 成本 |
| --- | --- | --- | --- |
| 云/雾/锈/污渍 | GPU fbm（共享 256² 噪声）[src:L4192-L4195] | seed | 每像素着色时算 |
| 表面雨湿/变化 | uniform 注入（uSl*）[src:L5318-L5318] | 天气状态 | 近零 |
| 建筑与载具 | 参数几何拼装+合并 [src:pretty:L1044-L1068] | 常量表 | 启动一次 |
| 重复单元 | InstancedMesh [src:L5461-L5461] | 实例矩阵 | 单 draw call |
| 标识文字 | Canvas 2D 排版+啃咬 [src:pretty:L33030-L33054] | 文本+seed | 启动一次 |

这些配方在 `.distill/distillation/recipes/02-rain-rust.md`、`.distill/distillation/recipes/04-mech-enemy.md` 中给出可复用的参数表与代码模式。

## 为什么"生成"比"携带"便宜

把本篇三类生成器与其等价的静态资产做一次预算对照（数字来自 `slice-bundle.mjs` 实测与运行时捕获）：

- **一张 4K PBR 贴图组**（albedo+normal+roughness，PNG）约 12-25 MB；等价的 fbm 表面是 ~40 行 GLSL（归一化后约 1.2 KB 字符）加一张共享 256² 噪声纹理（256 KB 显存）——**万分之一量级**。
- **一个中型建筑模型**（glb，含烘培）约 2-8 MB；等价的参数几何拼装是几十行 JS（`Box/Cylinder + applyMatrix4 + merge`），运行时顶点直接进显存 [src:pretty:L1044-L1068]。
- **整套 UI 字体图标**若用位图 sprite sheet 约 1-3 MB；等价的 Canvas 排版引擎（`qa()`）+ 系统字体约 3 KB 代码 [src:pretty:L33030-L33054]。

代价转向了运行时：启动期生成全部纹理与几何（游戏有明确的 onLevelReady 编译预热阶段 [src:pretty:L7000-L7024]），以及每像素的 fbm 计算（由画质档的 `volSteps/tex` 旋钮兜底 [src:pretty:L1044-L1068]）。**用计算换字节、用启动时间换分发体积**——这是单文件哲学的完整交易结构。

## 建设者的检查清单

照抄这套体系时按顺序核对：

1. 噪声纹理是否确定性（硬编码种子 `2654435769`）[src:L4206-L4206]？
2. 所有表面着色器是否共享同一张噪声纹理（而非各建各的）[src:L4192-L4195]？
3. 几何是否"拼装→合并→实例化"三级复用 [src:pretty:L1044-L1068]？
4. 文字是否 Canvas 排版而非位图 [src:pretty:L33030-L33054]？
5. 天气/环境变化是否走 uniform 参数而非贴图切换 [src:L5318-L5318]？
6. 启动期是否有编译预热承接生成成本 [src:pretty:L7000-L7024]？
