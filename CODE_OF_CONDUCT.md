# 社区行为准则 · Code of conduct

## 讨论与协作 · Working together

针对代码、证据与设计取舍提出意见，而不是评价参与者本人。尊重不同经验水平，给出能复现的反例，不以人身攻击、歧视、骚扰或泄露私人信息回应分歧。

These expectations apply to issues, reviews and other project spaces. Maintainers may remove material or restrict participation to protect contributors. To raise a concern, ask a maintainer for a private contact channel without naming the people involved in public. Report a software security concern using the separate [security policy](SECURITY.md).
